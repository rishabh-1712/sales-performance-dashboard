# Sales Performance Dashboard

An interactive Excel dashboard analyzing regional and category-wise sales performance.

## Features
- KPI Cards: Total Sales, Total Orders, Total Units, Average Order Value
- Region-wise Sales Bar Chart
- Category-wise Sales Split Pie Chart
- Interactive Slicer for dynamic region filtering
- Built using Pivot Tables and Pivot Charts

## Tools Used
Excel, Pivot Tables, Pivot Charts, Slicers, Data Visualization
